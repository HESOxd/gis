# Четыре кейса ГИС-портфолио

Общая территория для первых двух кейсов — Богородское и Преображенское: можно сравнить результаты на знакомой местности. Для каждого — отдельный репозиторий, воспроизводимый код, QGIS/геоданные, карта, README «задача → данные → метод → вывод» и текст поста. Первый кейс подготовлен для HESOxd/gis; посты готовятся как тексты для публикации, без автоматической отправки в соцсети.

1. **Школы и поликлиники пешком.** Текущая папка. Предварительный расчёт по OSM, исходные данные сохранены, ограничения обозначены. До окончательного выпуска: официальные реестры учреждений, проверка исходной таблицы населения, входов и маршрутов.
2. **Выбор локации кофейни.** Те же районы; гексагоны 200–300 м и пешеходные зоны обслуживания. Жители, офисы, метро и остановки против конкурентов. Сначала проверить доступность и сопоставимость фактического пассажиропотока; не выдавать число выходов метро за пассажиров. Нормировать показатели, опубликовать веса и чувствительность рейтинга к весам. Топ-5 — неперекрывающиеся кластеры с адресным ориентиром, аргументами и ограничениями. Цель: обоснованный шорт-лист для обследования, а не прогноз прибыли.
3. **Транспортная доступность центра.** До расчёта подтвердить наличие актуального открытого GTFS для выбранной территории и разрешение на использование. Проверить calendar/calendar_dates, пересадки и время сервиса свыше 24:00. Задать точную цель (например, один вход у центра) и фиксированные дату/время отправления; сравнить несколько утренних отправлений. Пешком и на машине — по соответствующим графам. Автомобиль без данных о пробках помечать как расчёт при заданных скоростях; не сравнивать с реальным часом пик как равнозначные наблюдения. Если московский feed недоступен, выбрать город с подтверждённым GTFS и явно согласовать смену территории.
4. **Зелень и жара.** Подобрать ясные летние сцены близких дат: Sentinel-2 L2A для NDVI и Landsat Collection 2 Level-2 для температуры поверхности. Обязательно применить маски облаков/теней и масштабные коэффициенты. Не создавать видимость 10-метровой точности температуры после ресэмплинга Landsat. Районные/сеточные средние с долей валидных пикселей; диаграмма и корреляция без причинного вывода. Температура поверхности — отдельная величина от температуры воздуха. Приоритеты озеленения учитывать вместе с жилой застройкой, чтобы водоёмы и промзоны не определяли рейтинг автоматически.

Стандарт качества: фиксировать дату и лицензию каждого источника, хранить параметры и контрольные суммы, отделять наблюдения от модельных оценок, показывать неопределённость рядом с результатом.
