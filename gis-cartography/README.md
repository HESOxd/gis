# Городское оформление портфолио

Вспомогательная папка для карт проектов 2–4. `src/extract_context.py` извлекает реальные улицы, парки/водоёмы и ориентиры метро из кеша OSM проекта 1 и готовых групп входов проекта 2. Сеть не используется. Расчёты проектов не меняются.

Готовые копии подложки включены в `data/cartography` каждого проекта. Их стили и функции отрисовки находятся в `src/map_style.py`, настройки QGIS — в `src/qgis_context.py`. Каждый проект можно перерисовать из собственной папки без этого вспомогательного каталога.

`src/update_qgis.py` запускается Python из QGIS, читает существующие проекты и добавляет подписи/контекст, сохраняя аналитические слои. `qgis_validation.json` содержит фактическое число повторно открытых слоёв; `analytical_payload_validation.json` — сверку прежних аналитических файлов с ранее переданными ZIP.

Подложка: © OpenStreetMap contributors (ODbL), снимок 01.11.2026. Дата снимка подложки отличается от спутниковых дат; улицы и метро служат ориентирами, не частью NDVI/LST.
