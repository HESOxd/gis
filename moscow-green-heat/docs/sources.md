# Источники и происхождение

Скачано 02.11.2026. Полные ID, UTC-время, геометрия, исходные URL и коэффициенты сохранены в `data/raw/*_item.json`; первоначальная выдача — `*_search.json`; хеши восьми обрезанных GeoTIFF — `manifest.json`. Обрезка сохраняет исходные DN, CRS и пиксельную сетку. Временные SAS-токены в архиве отсутствуют.

- [Sentinel-2 Earth Search](https://earth-search.aws.element84.com/v1/collections/sentinel-2-l2a), публичные COG `sentinel-cogs.s3.us-west-2.amazonaws.com`. Contains modified Copernicus Sentinel data 2025: модификация — обрезка, маскирование, NDVI и агрегаты. [Copernicus Sentinel legal notice](https://sentinels.copernicus.eu/documents/247904/690755/Sentinel_Data_Legal_Notice). В legacy STAC поле license стоит proprietary; это метаданные каталога, условия самого Sentinel проверяются по первичному уведомлению Copernicus, не по догадке о значении поля.
- [USGS Landsat Collection 2 Surface Temperature](https://www.usgs.gov/landsat-missions/landsat-collection-2-surface-temperature): продукт, коэффициенты, ограничения, свободное использование данных Landsat. [QA bands](https://www.usgs.gov/landsat-missions/landsat-collection-2-quality-assessment-bands): флаги облаков/воды/теней. Landsat 8–9 OLI/TIRS Level-2 Collection 2, USGS, DOI [10.5066/P9OGBGM6](https://doi.org/10.5066/P9OGBGM6).
- [Planetary Computer Landsat](https://planetarycomputer.microsoft.com/dataset/landsat-c2-l2), публичный STAC и бесплатное анонимное подписание [SAS](https://planetarycomputer.microsoft.com/docs/concepts/sas/). Никаких аккаунтов и покупок не создавалось.
- [Element84: обсуждение повторного offset](https://github.com/Element84/earth-search/issues/71). В выбранном item offset_applied=true; в коде явно зафиксирована гармонизация, противоречащий asset offset не вычитается повторно.
- Границы и жилые дома © OpenStreetMap contributors, [ODbL](https://www.openstreetmap.org/copyright), повторно использованы из проекта 1; исходные 30 XML и подробный журнал хранятся в соседнем `moscow-walk-access`. Локальные копии производных GeoJSON включены, поэтому расчёт проекта 4 автономен. Исходный снимок 01.11.2026; он не совпадает по времени с историческими спутниковыми сценами.

Для публичной версии нужно сохранить атрибуцию каждого источника и его условия; не объявлять всю папку одним новым владельческим набором данных. Полные GTFS-архивы в репозиторий не включены.
