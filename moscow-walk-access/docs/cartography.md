# Понятные городские карты

Школы и поликлиники оформлены с реальными улицами, метро и подписями. Цвет дома показывает рассчитанное время; номера связывают примеры с адресами справа. Все значения взяты из прежних результатов, расчёт не менялся. Коридоры сети сохранены в GIS-слоях; PNG объясняет доступность жилых зданий.

`src/plot.py` перерисовывает обе карты из готового GeoPackage. `src/map_style.py` задаёт общий стиль. Данные подложки в `data/cartography/`, источник — локальный OSM-снимок проекта 1 и группы входов метро проекта 2. Файл `src/interactive_map.py` создаёт офлайн-карту с улицами, метро и пояснениями. В QGIS доступны два именованных макета «Портфолио ·».
