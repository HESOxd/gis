# Методика и границы применимости

## Территория и сеть

Два административных полигона OSM получены через Nominatim. Все расстояния считаются в EPSG:32637 (UTM 37N), не в градусах и не в Web Mercator. Запас выгрузки — 2 000 м от объединения районов. Он превышает 15 минут × 5 км/ч. Учреждения по соседству включены; административная граница не ограничивает маршрут.

Загрузка идёт через read-only OSM API небольшими фрагментами, с кешем и паузой. Это запасной путь для небольшой территории: для всей Москвы нужен региональный PBF/экстракт или Overpass, а не множество запросов map API. OSM API включает историю объектов только в пределах предоставленной текущей версии. Исходные XML сохранены локально, из Git исключены из-за объёма. Их SHA-256 позволяет проверить снимок, но не восстановить его без архива.

Узлы совпадают только по ID OSM. Геометрическое пересечение двух линий не создаёт соединения — поэтому мост и дорога под ним не становятся перекрёстком. Рёбра неориентированные для пешего движения: автомобильный oneway не применяется. `oneway:foot`, условные запреты и turn restrictions сейчас не моделируются. Foot=no/private/use_sidepath исключаются; access=no/private исключается без явного разрешения foot. Велодорожка допускается при явном разрешении пешего прохода. Motorway/trunk исключаются без разрешения foot. Стены, заборы и запрещённые узлы-барьеры блокируют проход. Обычные ворота без запрета считаются проходимыми — это требует проверки.

Отдельных тротуаров может не быть в OSM. Если дорога не запрещает пешеходов, её ось служит приближением прохода. Модель не проверяет безопасность движения и доступность для коляски; ступени разрешены. Светофор, снег, уклон и часы работы не добавляют задержку.

## Объекты и входы

Школы — `amenity=school`. Для предварительной поликлинической выборки одновременно требуются упоминание «поликлиник» в имени и clinic/healthcare=clinic/centre. Исключаются явно частные и стоматологические объекты. Это консервативная выборка, а не полный реестр: неназванные и иначе размеченные поликлиники могут пропасть, специализированные — остаться. Детские и взрослые поликлиники пока объединены. Список для сверки — слой `facilities`.

Кампус школы, содержащий школьные объекты, заменяет вложенные объекты того же типа: это уменьшает двойной учёт территории и зданий. Независимые корпуса вне общей территории остаются отдельными. Полные multipolygon-отношения поддерживаются, неполные пропускаются и учитываются в отчёте.

Используется отмеченный вход на кольце здания/территории с кратчайшим соединением с сетью; если входа нет — внутренняя репрезентативная точка. Для школы это может быть приближение вместо настоящих ворот. Дом представлен одним входом, а не всеми подъездами. Прямой соединитель **не проверен на пересечение забора, воды или другого здания**; его длина ограничена 100 м. Модель не позволяет гарантировать физическую проходимость этих соединителей. Входы и красные дома нужно проверить вручную. Неудачно привязанные дома не входят в дефицит.

Привязка выполняется к ближайшему ребру; ребро разбивается в точке проекции. Время складывается из соединителя учреждения, пути по графу и соединителя дома. Это устраняет ошибку привязки к произвольному удалённому узлу.

## Изохроны и дефицит

Для изохрон Dijkstra запускается от каждого учреждения отдельно с бюджетом 1 250 м. Дополнительно для каждого типа учреждений вычисляются полные расстояния до домов без отсечения по времени; соединители учреждений учитываются через временный общий источник. Рёбра на границе бюджета обрезаются по оставшемуся расстоянию, затем формируется визуальный коридор ±18 м, растворяемый с точностью 1 м (упрощённые скругления). Из-за округления геометрии полигон 15 минут дополнительно объединяется с полигоном 10 минут для строгой вложенности. Это сетевые области обслуживания, а не утверждение о возможности пройти через каждую точку внутри полигона. Покрытие домов определяется временем по графу, а не пересечением этого коридора с домами.

`within_10` — до 10 минут включительно; `within_15` — свыше 10 и до 15 включительно; `over_15` — путь найден, но его время больше 15 минут; `unknown` — соединитель дома длиннее 100 м либо компонент сети не связан ни с одним учреждением данного типа. Поле `school_route_found` / `clinic_route_found` отделяет отсутствие пути в графе от большого времени. Разорванные компоненты не записываются в подтверждённый моделью дефицит. Неопределённость может отличаться для школ и поликлиник.

## Население

Районные итоги относятся к 01.01.2025; сеть — к 01.11.2026. Источник итогов **вторичный**, их ссылка на Росстат не означает, что первичная таблица проверена. Это отражено в `population_provenance.json`, README и посте.

Жилые здания выбираются по явным OSM-тегам apartments/residential/house/detached/terrace/dormitory/semidetached_house. Безымянный building=yes не считается жилым. Это может пропустить жильё. Нежилые доли смешанных зданий и незаселённые новостройки не определяются. Здания building:part отдельно не суммируются. Здание относится к району по внутренней точке, без деления между районами.

Для здания h: `p_h = P_района × (площадь_h × этажность_h) / сумма_района(площадь × этажность)`.

Пропуски этажности заменяются медианой по зданиям района с известной этажностью. Такой подход сохраняет районную сумму, но не измеряет реальных жителей по адресу. Сохранение суммы проверяется assert с допуском 1e-5. Округление происходит в итоговой CSV, поэтому округлённые категории могут отличаться на 1 человека. Оценки школы и поликлиники относятся к одним и тем же жителям и не складываются.

## Проверки и выпуск

`tests/test_network.py` проверяет запреты, разбиение ребра, частично достижимое ребро и отсутствие нулевого времени на разорванной сети. `quality_report.json` содержит параметры, пропуски, размеры графа и неопределённые случаи. QGIS-проект после сохранения повторно читается, проверяется валидность всех слоёв.

Перед выпуском полноценного кейса: получить актуальные выгрузки учреждений с data.mos.ru (зафиксировать ID, версию и дату), проверить их корпуса и адреса; сверить население с исходным XLSX; проверить входы и 10–20 пограничных маршрутов по карте/на местности; разделить взрослые/детские поликлиники; интерпретировать чувствительность к скорости 4 и 5 км/ч, уже рассчитанную в `speed_sensitivity.csv`. До этого версия предварительная.

## QGIS Python на этом Mac

Из корня репозитория:

```bash
QT_QPA_PLATFORM=offscreen \
PYTHONPATH=/Applications/QGIS.app/Contents/Resources/python \
PROJ_LIB=/Applications/QGIS.app/Contents/Resources/proj \
/Applications/QGIS.app/Contents/MacOS/bin/python3 src/qgis_project.py
```

Для другой установки настройте Python/PYTHONPATH/PREFIX по [документации PyQGIS](https://docs.qgis.org/latest/en/docs/pyqgis_developer_cookbook/intro.html). Проверено с QGIS 3.42.1. Проект хранит относительную ссылку на GeoPackage; всю папку нужно переносить вместе.
