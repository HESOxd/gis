# Что нужно для полного кейса до центра

Статус 02.11.2026: завершён реальный остановочный пилот. Городская доступность и три режима не рассчитаны. Отсутствующие результаты не заменяются условными скоростями по прямой.

| Компонент | Есть | Пробел и следующий проверяемый шаг |
|---|---|---|
| Наземное расписание | Июньский community-архив | Подтвердить дату актуализации у поставщика и действующие рейсы; проверить календарные исключения и полную GTFS-валидность |
| Метро, МЦК, МЦД | Нет подтверждённого полного источника | Найти расписания/интервалы, часы работы, пересадки и входы; проверить, что все режимы включены |
| Условия использования | URL публичный, явной лицензии нет | Установить право использования/распространения; локальная доступность файла не доказывает лицензию |
| Пешеходный граф | Локальный OSM проектов 1–2 | Он не доходит до Кремля. Нужен связный граф всей области поездок с переходами, входами и ограничениями; проверить привязки остановок и адресов |
| Автомобильный граф | Не подготовлен | Направления, ограничения поворотов/доступа, скорости; отличать свободный ход от наблюдаемого времени в пробках |
| Контрольная точка центра | Не выбрана/не привязана | Выбрать доступную пешеходу точку вне закрытой территории и одинаковые правила прибытия; зафиксировать координаты и проверенный вход |
| Матрица ячейка→центр | Нет | Сетка единого масштаба и несколько отправлений утреннего пика; подход, ожидание, пересадки, выход, лимит поиска и статусы ошибок |
| Сравнение режимов | Нет | Общие источники/назначение и временные сценарии; автомобильный подъезд и парковку описать отдельно, не считать их мгновенными |
| Карта неравенства | Нет | Не смешивать no-data, несвязный граф и действительно недостижимые ячейки; агрегировать с весами населения после проверки покрытия |

## Схема следующего расчёта

Для каждой ячейки и каждого отправления: привязать доступную точку к пешеходному графу → получить реальные пути к остановкам → рассчитать расписание с полным набором режимов/пересадок → добавить выход до центра. Отдельно посчитать пеший путь по тому же графу и автомобильный по дорожному графу. Сохранить отдельные составляющие времени и причины отсутствия результата. Сравнить медиану и разброс по отправлениям, проверить известные поездки вручную. Не считать теоретическую оценку свободного автомобильного движения эквивалентом движения в утреннем потоке.

Остановочный движок текущего проекта — проверенный небольшой компонент этой схемы. Он не поддерживает frequencies/transfers/pathways, внутривокзальные переходы и previous-day carryover; для полного расчёта нужны их реализация или полноценный транспортный маршрутизатор с проверенными настройками. Нормализация заголовков не исправляет недостающие транспортные режимы.

Недоступный producer `greens3.transitpdf.com` уже проверялся; ночные повторы не выполнялись. Для продолжения потребуется новый источник или изменение внешнего доступа, а не повторное чтение того же архива.
