# Понятные городские карты

Оформление обновлено 02.11.2026 по предпочтению пользователя: улицы, метро, читаемые подписи и короткие пояснения.

- Улицы и подписи извлечены из реального кешированного OSM проекта 1; повторной загрузки и смены источников анализа не было.
- Метро показано как ориентир по группам входов OSM из проекта 2. Маркер приблизительный: это не выбранный вход для маршрутизации и не измеренный пассажиропоток.
- Карта сопровождается панелью с объяснением цветов, номеров и границ вывода. Адреса в списках помогают найти территорию; они не означают доступное помещение или утверждённое место посадки.
- `data/cartography/` содержит переносимые GeoJSON подложки и `context_manifest.json` с происхождением и SHA. Контекстные улицы/метро не участвуют в аналитических расчётах.
- PNG/SVG и QGIS обновлены. Численные таблицы, исходные данные, геометрии аналитических слоёв, маски и результаты сохранены.

Перерисовка: `python src/plot.py` (проекты 2/4) или `python src/plot_pilot.py` (проект 3). Стиль и подписи находятся в `src/map_style.py`. Создание QGIS через Python QGIS: `src/qgis_project.py`, который подключает `src/qgis_context.py`. Для готовых файлов сеть не нужна.

Общая необязательная процедура повторного извлечения контекста — `../gis-cartography/src/extract_context.py`, она требует локальный OSM проекта 1. Копии готового контекста включены в каждый архив. Атрибуция: © OpenStreetMap contributors (ODbL).

В QGIS добавлены именованные макеты «Портфолио ·» для каждой карты/диаграммы. Свежие копии всех результатов собраны в [галерее](../../portfolio-maps/README.md); всего7карт и2диаграммы четырёх проектов.
